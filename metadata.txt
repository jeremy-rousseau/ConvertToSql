        Accessible via the toolbox.
        Key features:
        - Supports various data types (booleans, dates, numbers, empty/null geometries, and handling of apostrophes)
        - Generates one INSERT statement per feature
        - Allows for the restructuring of input fields and/or the re-projection of the source layer
